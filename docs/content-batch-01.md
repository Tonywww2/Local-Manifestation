# 第一轮内容：第一层与首批装备

状态：2026-10-09 已批准并接入0.7.0。效果口径由用户授权开发者决策；以下表格保留最初设计依据，其中“需补充”等能力缺口已经处理，当前实现与开发数值边界以[实装记录](history/content-batch-01-stage.md)为准。

## 范围与已确认依据

- 本轮提出 6 种普通敌人、2 种精英、1 个 BOSS 及其强化变体，30 件饰品（一档 12、二档 10、三档 8）、11 把武器、12 件防具、5 种消耗品，以及 6 个战斗组合模板。
- 保持当代背景、科技制造的魔力、探索者身份及个人据点。第一层具体地名、地域与同化缘由不在本轮定案；敌人外形只给辨识意向，不提前确定整体画风。
- “冷静、诡异、日常、荒谬”只作为背景基调，不给四者分配内容职责，不据此新增玩法要求。
- 饰品主要效果按约 10%、20%、30% 及以上分档；不是整件物品对最终战力的保证。三档允许强条件与强联动产生更高收益。
- 标准 12 饰品槽，每次战斗平均获得一个饰品；同名乘区相加，不同名相乘。武器、护甲和消耗品不自动套用饰品的三档体系。
- 已确认枪械使用现实名称与型号。本稿采用 M4 卡宾枪与雷明顿 700 步枪作为两把枪械候选；非枪械技术设备沿用功能性名称。
- 已确认不考虑套装奖励，装备按单件属性与效果自由组合。
- 数值只给效果量级、相对耐久、射程和节奏。百倍、千倍不是配装指标，不倒推出每层固定倍率。
- 初始三个玩法倾向都能使用所有候选装备；没有职业装备锁。武器与防具不堆叠，消耗品每堆上限 30。

## 第一层敌人

耐久以本层普通近战敌人为粗略参照。这里的低、中、高不对应已经确定的生命常数。普通怪以几次常规开局攻击可击败为起点，快速脆弱敌人更少，重装敌人更多；实际还需结合武器节奏估计。

作者使用的概念方向候选：拖行者对应“滞留”，袋中物对应“容纳”，负重者与封装者对应“负担”，吐屑者对应“排斥”，漏液者对应“渗漏”，透镜体及其精英对应“注视”。这些只是用于讨论的内容标签，初期玩家看到的仍是表中的观察性名称；不把标签写成已确定的宇宙真相，也不增加解释主线。

各敌人仍遵守距离参与仇恨、附近可攻击目标优先尝试攻击的既有规则。除另有声明的未来内容外，保留接触伤害。远程攻击与接触攻击的具体伤害值分别在实施时确定；当前运行器接触伤害为物理，不将电磁弹的类型自动套给接触伤害。

### 第一层 BOSS 候选：搬运者 / The Carrier

外形意向为较大的搬运结构与局部形体相连，仍能看出器物和躯体；概念方向暂与“负担、转移”相关。名称只描述探索者观察到的表现，不解释其宇宙层面的身份。

三个主要动作候选：

1. **前压**：慢速追近，造成物理接触威胁，让玩家调整站位。
2. **卸载**：停步并显示抛掷方向，发射一组低速物理抛掷物；抛掷后有短暂恢复。
3. **冲撞**：明显准备后沿已显示方向突进，结束后停顿。首次实现需要敌人攻击阶段与方向锁定能力。

战斗搭配少量拖行者、袋中物，优先沿用预设波次补充，不把实时召唤另设为首版必需能力。BOSS 与小怪合计的耐久、场面占用共同粗估，不直接将小怪数量与 BOSS 生命同时大幅提高。

强化版本沿用同一主体与招式辨识：耐久、卸载覆盖和恢复节奏有所增强，小怪组合更有压力；仍保留冲撞后的窗口。沿用已经确认的强化 BOSS 诅咒与层结束规则。是否增加新招式在本体方向确认后讨论，不自动增加无敌阶段。

## 饰品与乘区

装备互斥组和伤害乘区是不同概念。以下名称不隐式创建新乘区，不改变既有饰品互斥约束。

| 计算环节 | 本稿处理方式 |
| --- | --- |
| 六属性、生命、护甲、攻速、移速 | 同一属性的装备百分比进入同名装备组；同属性同组相加，其他计算环节继续独立求值 |
| 无条件造成某类伤害 | 统一进入既有“饰品”伤害乘区，按伤害类型筛选；不会因为物品名不同就彼此相乘 |
| 闪避后造成伤害 | 候选“行动”乘区，类似行动条件的内容共享；待批准 |
| 对符合条件的目标造成伤害 | 候选“目标状态”乘区，满生命目标和灼烧目标的对应内容共享；待批准 |
| 追加一次伤害 | 增加独立伤害段，不作为另一个伪装的最终乘区；同一次命中共用暴击判定，每段分别计算护甲，不生成新命中 |
| 百分比减伤 | 在固定护甲之后结算，不用攻击端的命中乘区代替 |

标记“需补充”表示尚不能只靠当前配置完成，不代表效果已批准或已实现。

本稿不增加弹药、耐久、装填、武器独立资源或新机体。技能与武器的原有资源规则不因名称改变。火焰与寒冷状态只由明确写出的武器效果施加，不由伤害类型自动施加。

## 获取与搭配提案

- 第一层的饰品奖励以一档为主，二档提供方向性选择，三档作为少量强力候选。已允许第一层少量直接获得三档，开发掉落配置见实装记录。
- 每次战斗平均一件饰品作为单独收益参照。武器、防具建议通过商店与部分战斗奖励补充；不以发放一件防具自动替代已确认的饰品平均收益。
- 普通掉落沿用玩家独立获取与自由交换规则。精英、更高压力模板的额外收益在人数收益设计中一起估计，不先决定保证掉落某档饰品。
- 本批内容覆盖六种伤害类型，四个元素增伤饰品都有对应武器可用，避免首批出现没有适用对象的基础伤害饰品。
- 典型近战方向可以组合力量、攻速、物理增伤、生命与行动条件；典型远程方向可以组合敏捷或感应、攻速、对应类型增伤和目标条件；法术方向可以组合智力、魔力、攻速、类型增伤与灼烧条件。不是职业或固定配方。
- 例如握力圈、节拍器、刻纹砝码分别作用于基础属性、攻击频率和直接物理伤害；同时装备刻纹砝码和配重护套时，直接伤害的同名饰品乘区相加。后续 Shift 展示来自实际求值，不将这些示例写成硬编码解释。

## 描述与 Hover 文案示例

名称、实际效果、叙述短句分开保存并分别本地化。默认 Hover 展示具体效果与条件；Shift 展示实际属性、伤害段和命名乘区。未获得角色上下文时只展示符号与来源，不伪造最终伤害。伤害过程遵守现有两位小数显示规则，底层不因文案提前舍入。

叙述只在少量内容中出现，不保证每件物品附带异常故事，也不解释梦境来源或同化真相。示例为待讨论文案：

- 握力圈：内侧留着另一种握法的压痕。
- 备用电容：标签上写着“醒来后检查”。
- 便签夹：背面有一张没有日期的采购清单。
- 双端耦合器：维修记录中，两端始终使用相同的编号。

物理短刃默认 Hover 的结构示例：

> 工具短刃\
> 物理 · 近战\
> 造成 {实际伤害} 点物理伤害。\
> 较快攻击，攻击距离较短。

Shift 详情引用求值结果：基础固定值、力量与敏捷贡献、实例强化、加算、各命名乘区、暴击情景与目标防御。普通预览伤害和具体目标受击结果明确区分，不把最低伤害或目标护甲隐藏在显示值里。

## 最初的机制边界（现已补齐）

当前可直接承接的能力：属性百分比、命名伤害乘区、固定护甲、类型抗性、独立百分比减伤、攻速、近战前后摇、移动剑气、穿透、追踪、混合伤害段、灼烧、持续回复、固定容量护盾、消耗品与交易。

本次已按用户授权补齐以下能力，具体语义见实装记录：

1. 敌人独立的准备、出手、恢复阶段，以及短突进与方向锁定；仅有时间取模的 JS 决策不足以完整表达受控、暂停与恢复中的阶段。
2. 装备暴击伤害与治疗修正属性。
3. 闪避事实、对应条件状态及命中条件快照；不能把攻击命中与追加伤害后事实混为新的命中触发。
4. 比例追加伤害的只读攻击输入与基础取值；计算一次完整贡献，再由权威所有者提交。
5. 固定护甲之后的条件减伤；不能用护甲之前的攻击端乘区模拟。
6. 每次战斗一次的护盾记账与最大生命快照；不能靠进房次数或波次次数发放。
7. 寒冷武器的减速状态与控制抗性适用范围。
8. 三档在第一层的获取范围、武器防具的奖励来源，以及与平均饰品收益的组合。
