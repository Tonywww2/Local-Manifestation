# 四方向部件动画资源契约

`animation:rigs` 指向标准 JSON 配置，`rig:<完整机体或敌人定义 ID>` 指向对应 RGBA PNG。运行图为 6 列 × 4 行，默认 1536×1024；加载器接受能整除 6×4 的尺寸，最大边仍受资源加载器的 4096 上限约束。整包图片和声音解码预算为 256 MiB。

列顺序固定为 `body`、`head`、`arm_left`、`arm_right`、`leg_left`、`leg_right`。行顺序固定为 `front`、`back`、`right`、`left`。左右按角色自身左右命名。镜头旋转后，使用屏幕上的朝向向量选择行；游戏世界坐标与判定不变。

每格仅包含一个竖直、独立部件。手臂包含手，顶部为肩；腿包含脚，顶部为髋。躯干不再包含头、手臂与腿。非人形对应核心、上部特征、左右附肢、左右底部。每格在加载时按 alpha 大于 32/255 的可见区域裁空边；美术不应留下不属于部件的背景残留。

配置例：

```json
{
  "version": 1,
  "rigs": {
    "base:scout": {
      "profile": "humanoid",
      "height": 4,
      "clips": { "move": { "amplitude": 1, "speed": 1 } }
    }
  },
  "weapon_clips": { "base:carbine": "rifle" }
}
```

`profile` 使用 `humanoid` 或敌人外形分类（如 `bag`、`load`、`lens`、`array`、`leaker`、`encased`、`carrier`、`spitter`）。未指定 `height`、`bones`、`draw_order` 时，使用 `pkg/animation.DefaultRig` 的对应默认值。`height` 是显示基准半径的倍率，仅影响画面：玩家基准为12，敌人优先使用定义中的 `visual_radius`，未声明时兼容使用 `radius`。

可选的 `bones` 必须是完整六元素数组，每项提供 `parent`、`offset`、`size`、`pivot`。`parent` 为 -1 表示根节点，否则必须引用下标更小的骨骼。默认头、双臂、双腿都继承躯干的位置、旋转和缩放。`offset` 与 `size` 以整个人物高度为单位，坐标原点为脚下地面点；`pivot` 为裁切后贴图中的 0–1 比例。贴图在部件尺寸内保持宽高比。`draw_order` 是四行、每行六个不重复骨骼下标的完整数组。

`weapon_clips` 可按武器定义覆盖动作分类：`melee`、`pistol`、`rifle`、`cast`。可选 `clips` 支持 `move`、`attack:<分类>`、`skill`、`hit`，每项给出 `amplitude` 与 `speed`；速度倍率仅用于移动步态，不改变攻击、技能与闪避的权威时间。

加载器只解码、裁切和上传一次；24 个部件引用同一张 GPU 图集。每帧使用固定数组采样父子骨骼变换，按绘制顺序提交缓存子图。手持武器沿用 `art:layout` 中的握点，并附着于右手端点。缺少图集时保留原有静态外观。

敌人的世界位置表示全身碰撞圆心。加载时缓存四方向静止姿态的可见部件包围盒中心，绘制时将此中心对齐世界位置；骨骼仍使用原有脚底局部坐标。显示尺寸与碰撞尺寸独立，调整 `radius` 不会再次放大贴图。移动、接触伤害、受击、障碍寻路与边界夹取共用固定的服务端 `radius`，不随客户端镜头、朝向或某帧动画变化。当前使用覆盖全身与常规动作幅度的圆形近似，不是逐像素轮廓。

更新原版敌人美术或骨骼后，可运行 `tools/go.ps1 run ./tools/artpack/enemy-collision -report docs/art-v1/enemy-collision.json` 重新校准；确认定义后加 `-check` 核对。工具与客户端复用透明裁切、部件等比尺寸和骨骼角点计算，覆盖四方向、移动、近战/施放攻击与受击回摆；服务端仅读取已写入内容的数值，不加载图片。

玩家的移动步态、攻击、武器技能、闪避、受击与生命周期来自服务端显示快照。敌人的死亡记录只保留位置、半径、定义 ID 与动作时间等值，不再包含碰撞、AI、掉落或受击目标。末只敌人死亡时，这份视觉记录会由战斗场景转交同节点的自由空间，短动画结束后清除。

渲染帧与逻辑刻独立；插值按快照时间采样，并仅对最新显示动作补间最多 100ms。暂停冻结活体攻击和移动；倒地、死亡的纯显示过渡仍可收尾，不推进状态、攻击判定或战斗时间。
