# 实际跨房、周边加载与实体投票

日期：2026-10-08。本页记录协议 7 / SDK 3 / 检查点 3 的跨房阶段；当前已升级至协议 8 / SDK 4 / 检查点 4，连续坐标交接与状态实现见[后续记录](movement-status-stage.md)。该历史阶段的版本说明：客户端、服务端和原版内容一起更新；本批地图内容摘要改变，旧内容的检查点不能直接恢复。个人 profile 的语言、布局和自定义绑定保留。

## 已实现的移动

玩家实际走到六边形边缘的入口后跨房。只有地图中显式连接的相邻格有入口，不能从地图点击传送，也不能用远处节点请求绕过路径。原版测试地图的每条连接增加一个免费六边形通路；悬崖、山壁属于无房间地形，没有入口、演员或奖励。

免费通路和已清理战斗房间自动通过：在开口附近继续朝外移动。未完成的个人行动力房间按 G 检查入口，再在可拖动的窗口中确认费用。确认后才扣个人行动力。共享门批准后，玩家仍自行确认是否进入；普通共享门投票不会把全队拉入房间。初始等待与普通波次间隔允许外部玩家付费加入，开战锁门；全员倒地暂停的房间仍可依法入场支援。

G 是两种输入模式默认的交互键，可在设置修改。旧设置自动补充该动作；如果 G 已绑定其他动作，选用空闲键，不覆盖原绑定。F7 保留救援、强化等开发操作，选中节点入场也必须通过距离校验。

服务端检查当前空间、完整碰撞圆、真实相邻连接、入场时机和费用，并验证节点脚本及其操作后才提交。战斗 actor 接收入口落点和完整玩家值；协调器随后停止写入该玩家坐标。拒绝入场、脚本失败和重复请求不会部分扣费或留下双重实体。该阶段换房清理鼠标目的地、旧输入和显示历史；后续免费入口已改为保留并转换持续输入；重连保留服务端位置。

## 周围一圈与移动显示

客户端默认加载当前房间及六个相邻位置上的实际房间，包括相邻但没有连接的房间；是否能走仍由真实入口决定。地形不作为房间加载。房间局部地面/网格/边界缓存为纹理，走动时镜头跟随并平移纹理。优先准备当前房间，再每帧准备一个邻房；离开一圈的缓存释放，避免缓存无限增长。周边队友与正在发生的战斗读取服务端快照，不提前启动尚未进入的战斗或发放收益。

地图轴坐标用于拼接显示空间，房内实体仍使用自己的世界坐标。不同尺寸的房间按统一六边形格投影显示；两种视角共享同一变换，鼠标反投影回当前房间坐标。房间模拟依然独立。

本机角色不再进入其他实体使用的 100 毫秒插值缓冲。普通移动用当前输入立即推进显示位置，再平滑校正服务端偏差；边界、跨房、倒地和大幅位置变化会约束或重置预测。预测只影响显示，不提交生命、行动力、节点、奖励或命中结果；闪避与战斗结果继续以服务端数据为准。其他实体继续插值。显示推进按实际时间计算，不改变服务端固定 30/60 TPS。

## 实体装置与字幕

共享门口的装置支持 G 交互投票。在线、存活且参与本层的决策成员需先各自抵达目标房间任一门口。再次交互撤票，离开装置范围、倒地或断线也会撤回自己的票；没有支持票时取消投票。达到房间配置的通过比例才扣共享行动力并开门。装置显示有效票数和通过所需票数，没有团队投票窗口。

非最终层 BOSS 清理后保留在本层出口房间，阶段为 `intermission`。与出口装置交互并留在范围内投票，通过后才准备新层行动力、地图和层间检查点；检查点写入失败保留原层状态。初次开局及恢复层间检查点仍使用已有开始流程。最终层清理仍进入通关。

共享池为零时提供强化出口装置，保留进入前的个人行动与救援机会；开发用强制耗尽也使用范围内投票。此类装置在房间内靠边位置，避免与中央敌人出生区重合。

服务端快照提供初始等待及波次间隔的剩余秒数，客户端在当前房间中央以字幕显示倒计时。字幕不打开窗口、不暂停游戏，也不以客户端时钟改变波次开始时间。

## 验证

- 完整 Go 测试、vet 和相关模块竞态检查通过。真实 TCP 测试使用移动输入抵达入口，覆盖分房战斗、重复请求、波次锁门/加入、断线重连、自定义房间/节点、单人装置及三层出口投票。
- 几何与事务测试覆盖六个入口方向、反向落点、不可穿越的边界、免费通路、远处伪造入口、队员位于不同入口、投票期间离开、脚本失败和检查点失败回滚。
- 显示测试覆盖本机在新快照到达前移动、30/60/120/240 FPS 下相同移动距离、跨房预测重置、第一圈筛选、自定义旧按键保留以及共享投票不打开窗口。
- 八个真实 TCP 连接捕获起点、免费通路、个人入口等待和 A/B 并行战斗；原生画面验证 1024×720、1280×800、1920×1080、中英文、双视角、可拖动入口确认窗及中央字幕。
- 双原生客户端性能基线：120 FPS 上限、VSync 关闭、60 TPS、输入 60 Hz，实际走动跨房并展开长伤害解释。活动战斗样本平均 FPS 为 114.05 / 114.04，双方场景 TPS 与输入频率均为 60.00。此为本机结果。
