## 已交付

- 战斗相机使用完整窗口，HUD 叠加；按实际窗口尺寸布局，俯视/斜俯视继续共享世界坐标。
- 左上四技能与四消耗品；右上小地图、视角按钮及同房间优先的队友栏；底部血条和状态、右下武器/护甲/背包入口。行动力显示在小地图内部左下，血条右侧两个实心/空心圆点表示当前闪避储存。
- 大地图、背包、武器、护甲、本人/队友信息、准备、设置、开发面板及 Hover 共用可拖动标题栏。浮窗拖动后保存位置；Hover 拖动后固定阅读，关闭后恢复普通悬浮。鼠标跨越控件到 Hover 的间隙时有短暂保留，内容失效或失焦时清理。
- Shift 仅展开聚焦窗口或 Hover 的详情，不弹出全局武器面板。武器摘要显示无暴击、无目标防御的预计伤害；展开复用属性贡献和伤害步骤，并标出最近一次服务端结算。明细支持滚轮、PgUp/PgDn。
- 状态左键不打开额外页面。现有倒地惩罚与诅咒提供真实摘要、永久时间及 Shift 计算示例，永久时间标记与快捷键分开。正式整体等级、限时层、历史来源还没有对应网络数据，界面不虚构这些数值。
- 设置包含语言、按键、布局编辑、帧率和 VSync。语言和绑定修改使用草稿，保存/取消与绑定恢复默认可用；两种操作模式分开保存，同模式冲突和 F2–F7 保留键拒绝覆盖。支持单键及鼠标键，暂不支持组合键。
- HUD 布局编辑可以拖动各常驻组和样例窗口，保存/取消/恢复默认；JSON 记录稳定 ID、锚点及偏移，缩小窗口不改写原偏好。浮窗位置自动保存，设置草稿完整验证后才提交；文件采用同目录临时文件替换，保存失败保留旧文件并提示。
- 本人详情保留生命、等级、经验、货币、六属性、剩余点数及服务端加点操作。UI 输入先于游戏意图处理，点击窗口不会同时攻击；设置与布局编辑期间停止本地移动/攻击意图，但不暂停服务端。

## 模块与边界

`internal/client/ui` 只包含纯几何与布局函数，不依赖图形或 I/O。客户端宿主拥有窗口顺序、焦点、拖动和配置草稿；Update 构造显示值并处理输入，Draw 读取显示值。配置写入位于 `settings.go`，绑定校验位于 `bindings.go`，窗口和 Hover 复用同一套控件值与文字布局。

公式继续来自 `pkg/stats`、`pkg/damage`，预览按快照/语言变化重算，长文本换行采用有上限的缓存。没有为每个渲染帧重新求值，也没有新增共享写入的 UI/模拟全局状态。

## 本开发版的边界

技能/消耗品槽、护甲槽及背包内容目前是明确空槽；未接入装备、物品或交易事务。状态栏使用旧惩罚/诅咒适配，正式状态核心、冒险时间、独立层计时、多段伤害及护盾继续按 S1–S4 实施。

地图点选只查看，实际入口跨房、免费连接房间及不可进入地形仍待 N1–N3。为了保留现有流程测试，在大地图选节点后用 F7 开发面板入场/发起共享投票；救援、强化、耗尽共享行动力及强化 BOSS 也保留在该面板。这是临时开发入口，不是已完成的空间玩法。

连接表单仍沿用原有文本按钮。最终美术、组合键、模组 UI 注册及非游戏状态下的完整 HUD 样例后续接入。

## 验证

- 完整 `go test ./...`、`go vet ./...`，客户端及纯 UI 包的 `-race` 检查通过。
- 行为测试覆盖：状态左键不打开页面、Shift 不展开无关窗口、顶层命中隔离、锚点拖动/缩窗恢复、地图选择不改权威状态、按键冲突/模式隔离/重启恢复、保存失败及保留未知配置字段、同房间排序、闪避圆点与行动力归属。
- 原生截图覆盖 1024×720、1280×800、1920×1080，中英文、双视角、八人 HUD、设置/绑定、背包/地图及武器/状态 Shift 详情。
- Windows 客户端/服务端/模组工具及 Linux amd64 服务端交叉编译通过。
- 本机双原生客户端分房战斗，双方均展开长伤害解释，设定渲染上限 120、关闭 VSync、服务端 60 TPS、输入 60 Hz。启动两秒后的活动场景样本平均 FPS 为 111.06 / 109.97，场景 TPS 均为 60.00，输入均为 60.00 Hz。性能数据是本机开发测试结果，不保证其他设备达到相同 FPS。

两台独立设备、公网可达性、正式状态生命周期及物理跨房仍需各自验收。本机截图和双连接不替代这些项目。
