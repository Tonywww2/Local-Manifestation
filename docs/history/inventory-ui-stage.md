# 背包与状态界面迭代

2026-10-09，基于开发版 0.7.0。本轮仅调整客户端界面，不改变协议13、SDK6、内容格式3、检查点6或默认内容摘要。

## 已接入

- 右下单一卡片替代武器、护甲、背包三个按钮与原左上货币成长栏。卡片显示实际装备武器、金钱、等级、经验数值与进度条；Hover 显示未分配点数，Shift 复用武器伤害解释。
- 点击卡片打开 RPG 式背包。左侧显示角色立绘与一武器、四护甲；左下显示四消耗品和当前四技能；右上显示饰品；右侧其余区域显示27个固定背包格。
- 立绘优先读取材质资源 `portrait:<机体ID>`，其次复用 `player:<机体ID>`；没有贴图的机体使用基础现代探索者轮廓。武器、防具槽沿用实际内容与物品实例。
- “属性与加点”按钮打开独立普通窗口，可拖动、关闭、与其他窗口共存。关闭背包仅回收手持物品，不关闭属性窗口。
- 属性窗口保留服务端加点事务；显示六项基础属性、生命、护甲、速度、攻速、技能资源与恢复、护盾、治疗、暴击、武器预览及各伤害类型的当前百分比防御。滚轮查看长列表，聚焦后 Shift 展开来源和公式；六属性也有独立只读 Hover。
- 保留左键取放、右键半堆/单个、战中换装、不自动整理、关闭时回收鼠标槽。特殊模式扩容的背包与饰品分别分页；小窗口沿用滚动裁切，固定标题和底部入口。
- 技能区域展示当前配置与快捷键、冷却和说明。本轮没有新增技能替换规则。
- 卡片继续使用原 `equipment` 布局 ID，已保存的 HUD 位置仍生效。旧 `wealth` 位置不再生成可见栏位。中英文同步更新。
- 小尺寸窗口收窄底部资源/状态区域，并减少队友栏的同时显示数量，为新卡片保留空间；剩余状态和队友继续通过原有滚动或更多提示查看。

## 代码边界

`internal/client/ui/character.go` 只计算区域与网格几何。`character_inventory.go` 构造控件值，继续调用原有物品事务。`character_stats.go` 提供独立属性窗口；属性求值、伤害和防御均读取权威快照与既有内容模块，派生说明按快照/语言缓存。`character_draw.go` 只绘制显示值与资源。没有增加游戏暂停、窗口父子销毁关系或每帧世界复制。

## 本轮检查

- Windows 客户端、服务端、模组工具及 Linux 服务端编译通过；最终界面修订后重新编译客户端。
- 少量原生静态快照渲染：1280×800中文背包、英文HUD、640×480英文属性窗口；补查小尺寸背包的内容裁切与滚动。
- 这些检查仅验证原生绘制，不等同于真实联机物品事务或人工操作验收。本轮没有运行全量测试、竞态检测或性能回归。

## 玩家待测

1. 换装、收入、升级后，入口卡片上的武器、金钱、等级与经验是否及时更新；Hover / Shift 是否正确。
2. 背包所有区域的左键取放、右键拆堆/放一个、战中换装；关闭时手持物品是否返回背包，空格是否保持原位。
3. 打开属性窗口后关闭背包，确认它仍可独立显示、拖动、滚动与加点；核对装备或状态变化后的数值和来源。
4. 中英文、不同机体、不同窗口尺寸；小尺寸滚动后装备/技能、标题与底部按钮是否正常命中。
5. 特殊模式大背包、多饰品和无限饰品的独立分页、最后一页与满容量边界。
6. HUD 编辑中拖动并保存新卡片，重启后核对位置；与地图、交易、设置等窗口叠放时检查焦点和输入遮挡。小尺寸下另查8人队友栏与多状态栏的滚动显示。
