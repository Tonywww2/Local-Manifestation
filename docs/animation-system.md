# 人物与敌人动画

2026-10-15 已确认采用部件骨骼动画，身体按正面、背面、右侧、左侧四方向展示，允许后续内容镜像复用。保持现有战斗判定；前摇、出手、后摇、闪避和生命状态来自服务端，客户端按渲染时间采样姿态。动画不创建额外伤害、不改变碰撞体、不延迟击杀与掉落结算。

第一批人物动作：移动、攻击、武器技能、翻滚、受击、倒地、死亡。敌人动作：移动、攻击、受击、死亡。武器按近战、手枪、长枪、施放类共用基础动作，特殊武器允许配置覆盖。敌人死亡后短暂播放动画并消失，不保留永久尸体。死亡显示记录与活着的敌人实例分离。

人物非攻击移动时朝向实际移动方向，静止保留上次方向；攻击前摇至后摇及武器技能期间朝向已接受动作的方向。移动鼠标不会让静止或非攻击行走的身体转向。大厅、战斗和自由空间使用同一纯函数规则，本地玩家额外用当前输入减少显示延迟；远端玩家使用服务端朝向。镜头旋转之后才选择四方向贴图，攻击判定仍使用世界中的瞄准方向。

## 内容与运行边界

- 透明部件图在 `content/base/assets/art-v1/animation/`。每张1536×1024，6列×4行；行依次为正面、背面、右侧、左侧，列依次为身体核心、头部/上部特征、左臂/左附肢、右臂/右附肢、左腿/左下部、右腿/右下部。非人形敌人保留自身身份，不强制人类解剖。
- `animation:rigs` 注册 `rigs.json`，`rig:<定义ID>` 注册对应纹理。JSON 定义骨骼位置、大小、枢轴、父节点、方向遮挡顺序及动作调节。武器贴图继续独立持握。
- `pkg/animation` 提供显式输入、固定大小返回值的纯函数姿态采样。客户端负责读取资源、选择屏幕朝向并提交 GPU 绘制。镜头旋转只影响显示方向，不修改世界坐标。
- 服务端拥有动作序号和动作时间；连续移动通过移动向量及步态进度驱动。重复快照不能重播同一动作，暂停房间冻结攻击、移动、技能与翻滚；已经开始的倒地、死亡显示过渡可以收尾，不推进战斗判定或计时。
- 每份图在资源加载阶段解码上传，按格生成 GPU 子图并缓存。运行时不逐帧切图、重新上传或复制整个世界。发布新内容时更换整份只读资源代际。

完整图片提示词、原图及SHA-256记录见 `docs/art-v1/animation-players-and-enemies.json`、`animation-enemies.json`。最终实际检查与待测项目见[实装核对](implementation-audit.md)。

JSON字段、覆盖方式与约束见[骨骼内容契约](skeleton-contract.md)。
