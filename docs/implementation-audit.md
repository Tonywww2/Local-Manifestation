## 前批检查记录

- Windows 客户端、服务端、模组工具与 Linux 服务端编译。
- 两项必要定向检查：复活后计数/再次死亡边界；共享暴击、逐段护甲、护盾顺序、生命损失与过量。
- 纯 Go 示例的 SHA-256 安装、组合解析、归档编译及三宿主静态重链接；原项目源文件未被生成器改写。
- 一个短时本机 TCP 流程：两个连接、开层、装备护甲（5）、护盾（60）、双方确认交易、检查点生成。同电脑连接不等于独立设备验收。
- 少量原生背包渲染检查，仅验证绘制，不代替实际鼠标操作。

没有自动运行全量测试、竞态、性能回归、八人分房或完整三层通关。
