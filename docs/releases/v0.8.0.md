### 下载与启动

- **Windows 玩家**：下载 `LocalManifestation-0.8.0-windows-amd64.zip`，完整解压后运行 `client.exe`。内含客户端、本地/独立服务端、模组工具、原版内容、SDK 源码、中英文语言包和操作说明，无需安装 Go 即可游玩原版。
- **Linux 开服**：下载 `LocalManifestation-0.8.0-server-linux-amd64.tar.gz`，解压后按包内 `README.md` 启动。这个包仅提供独立服务端；玩家使用 Windows 客户端。
- 下载后可使用 `SHA256SUMS` 校验压缩包。包内 `BUILDINFO.json` 记录版本、源码提交和构建工具链。

### 当前内容

- 默认支持单人及最多8人的合作探索，服务端统一裁定，队友可在不同节点行动。
- 六边形节点网络、个人/共享行动力、连续移动与移动道具，5层主流程及后续无限探索。
- 多种初始机体、武器技能、四部位防具、饰品、消耗品、状态和可展开的伤害公式；当前包含72件物品与13类敌人。
- 独立房间与复合六边形场地、四方向部件动画、正交视角旋转缩放、可编辑战斗HUD、背包交换与地面拾取。
- 中英文切换、按键设置、性能与网络监控，以及 JSON / JS / Go 内容扩展结构。

### 开发版本说明

这是持续迭代的开发版本，内容、平衡与存档格式仍可能变化。客户端、服务端与玩法内容需要使用相同版本。未提供公网托管、自动端口映射或 Steam 接入；异地开服需使用可被队友访问的服务器地址。

本次发布以编译、打包完整性与必要的短时启动检查为验收范围，尚未进行完整多人回归。建议优先体验单人开局、两台设备加入、房间战斗、背包与地图移动，并反馈问题。

First public development release of **Local Manifestation**, a contemporary 2D co-op roguelike built with Go and Ebitengine.

Download the **Windows AMD64 ZIP**, extract the entire archive and run `client.exe`. Go is not required to play the base game. The **Linux AMD64 tar.gz** contains the dedicated server only. Verify downloads with `SHA256SUMS`; `BUILDINFO.json` identifies the exact source commit and toolchain.

Supports solo play and up to 8 players by default, separate-room co-op, hex-node exploration, equipment builds and damage formulas, Chinese/English localization, configurable controls and HUD layouts. This is an evolving development build; balance and save compatibility may change. Use matching client/server versions. Hosting requires a reachable address; public hosting and Steam integration are not included.
