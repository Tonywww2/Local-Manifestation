## 已完成的战斗外动作基础

- 战斗和普通房间共用 `internal/scene/player_step.go`，按固定步进处理移动、攻击前后摇、闪避与充能。

- 停止输入仍恢复闪避次数，短按输入锁存一次；检查点排除临时弹体。

- 按敌人模板、冒险阶段、节点变体与参战人数预设成长，保留强构筑的超额收益；不根据实际玩家输出实时追涨敌人生命。
- 第一层以初始装备能够应对为起点；第二层允许零散成长、尚未成形的构筑推进；第三层通过明显的装备成长应对更复杂组合；第四层增加组合与机制压力；第五层以完整构筑约四成最终综合战斗能力可通关作为普通难度参照。
